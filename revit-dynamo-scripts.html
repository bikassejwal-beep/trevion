Dynamo Python Scripts for Revit MEP

Six working scripts for everyday BIM tasks: move parameters in and out of Excel, check a model for common problems, tag elements, take off quantities, and create views and sheets in bulk. Copy them, run them in Dynamo, and adapt them to your standards.

Get the Scripts Read the Setup Guide
Before you start: try every script on a copy of your project first and review the results against your project standards. Scripts that change the model do it in a single step, so Ctrl+Z in Revit undoes the whole run.

What Is Included

Each script is a single Python Script node for Dynamo. No packages to install.

Parameter Manager

Move parameters between Revit and Excel, and import only the cells you changed.

Model Checker

Read-only QA report for empty parameters, untagged elements and duplicates.

Auto-Tagger

Tag every untagged element in the active view with one run.

Quantity Takeoff (BOQ)

Counts, lengths and areas grouped by type, ready in Excel.

Sheet and View Automation

A view and a sheet for each level, with the view placed on the sheet.

Batch Sheet Maker

Create many sheets from an Excel list, with views and parameters.

Requirements

  • Autodesk Revit with Dynamo for Revit. The Python engine used by these scripts is PythonNet3.
  • Auto-Tagger needs Revit 2022 or later.
  • Microsoft Excel, or any spreadsheet app that can save CSV UTF-8.
  • A folder for the files the scripts write. The examples use C:\Temp. Create it first.
  • For Auto-Tagger, the tag families for your categories (for example Duct Tag and Air Terminal Tag) loaded in the project. For the sheet scripts, at least one title block family.
Setup Guide

How to Run Any Script in Dynamo

The steps are the same for all six scripts. Only the inputs change.

  1. Open Dynamo from Revit. Open your project (a copy is best), go to the Manage tab, and click Dynamo. Then choose File > New.
  2. Add a Python Script node. Search for "Python Script" in the library and drag it onto the canvas. Click the + on the node until it has as many inputs as the script needs. Each tool below lists its inputs.
  3. Add one Code Block per input. Double-click empty canvas and type the value. Text needs quotes, for example "Ducts";. Paths need double backslashes, for example "C:\\Temp\\params.csv";. True and false have no quotes: true;.
  4. Wire the inputs in order. Connect the first Code Block to IN[0], the second to IN[1], and so on. The order matters.
  5. Paste the script. Double-click the Python node, delete the default code, paste the script, and click Save Changes. The first line must be # -*- coding: utf-8 -*-. Do not paste anything above it.
  6. Add a Watch node and run. Connect a Watch node to the OUT port. Set the run mode to Manual at the bottom left of Dynamo, then click Run. The script reports what it did in the Watch node.
  7. Running it again. If you change the model in Revit and click Run, Dynamo may not run the node again because its inputs did not change. Change the run toggle to false;, run, change it back to true; and run again. Clicking Save Changes in the Python node also works.

1. Parameter Manager

Export parameter values for a category to CSV, edit them in Excel, then import the changes back into Revit. Useful for filling Mark, Comments, System Name and other parameters across many elements.

Inputs

PortWhatExample
IN[0]Mode"export"; or "import";
IN[1]Category"Ducts";
IN[2]CSV file path"C:\\Temp\\params.csv";
IN[3]Parameter names["Mark", "Comments"];
IN[4]Run toggletrue;

Supported categories: Ducts, Duct Fittings, Duct Accessories, Air Terminals, Pipes, Pipe Fittings, Pipe Accessories, Mechanical Equipment, Plumbing Fixtures, Electrical Equipment, Electrical Fixtures, Lighting Fixtures, Cable Trays, Conduits, Sprinklers, Rooms and Spaces.

Procedure

  1. Set the mode to "export" and run. The Watch node shows how many elements were written, and the CSV appears at your path.
  2. Open the CSV in Excel and edit the parameter columns. Do not delete the ElementId column. Save as CSV UTF-8 (Comma delimited), then close Excel, because an open file is locked.
  3. Change the mode to "import" and run. The Watch node shows how many values were updated and skipped.
  4. Check a few elements in Revit. You can use Manage > Inquiry > Select by ID with an ElementId from the CSV.

Good to know

  • Only values that differ from the model are written.
  • Read-only parameters and invalid values are skipped and listed in the report.
  • The whole import is one step. If an error happens, everything is rolled back.
  • Numbers with units use your project display units, for example millimetres.
  • Excel can change values such as 007 into 7. Check these before importing.
parameter_manager.py
# -*- coding: utf-8 -*-
"""
Parameter Manager - Dynamo Python Script Node (Revit)
Export / Import parameters using an Excel-friendly CSV file.

SETUP IN DYNAMO:
  1. Add a Python Script node and paste this code.

  2. Inputs (IN[0] ... IN[4]):
       IN[0]  mode        : "export" or "import"
       IN[1]  category    : "Ducts", "Pipes", "Mechanical Equipment", ...
       IN[2]  file path   : r"C:\\Temp\\params.csv"
       IN[3]  parameters  : ["Mark", "Comments", "System Name"]
       IN[4]  run         : True (Boolean toggle; False disables execution)

  3. OUT: Message / report.

  Tip: Run "export" first, open the CSV in Excel, edit the values,
  save it as CSV, and then run "import".
"""

from __future__ import unicode_literals
import clr
import io

clr.AddReference("RevitAPI")
clr.AddReference("RevitServices")

from Autodesk.Revit.DB import (
    FilteredElementCollector, BuiltInCategory, Category, ElementId,
    StorageType, Transaction
)
from RevitServices.Persistence import DocumentManager

doc = DocumentManager.Instance.CurrentDBDocument

mode = str(IN[0]).strip().lower()
cat_name = str(IN[1]).strip()
path = IN[2]
param_names = [str(p) for p in IN[3]]
run = IN[4]

# ----------------------------------------------------------------
# Helper functions

CATEGORY_MAP = {
    "ducts": BuiltInCategory.OST_DuctCurves,
    "duct fittings": BuiltInCategory.OST_DuctFitting,
    "duct accessories": BuiltInCategory.OST_DuctAccessory,
    "air terminals": BuiltInCategory.OST_DuctTerminal,
    "pipes": BuiltInCategory.OST_PipeCurves,
    "pipe fittings": BuiltInCategory.OST_PipeFitting,
    "pipe accessories": BuiltInCategory.OST_PipeAccessory,
    "mechanical equipment": BuiltInCategory.OST_MechanicalEquipment,
    "plumbing fixtures": BuiltInCategory.OST_PlumbingFixtures,
    "electrical equipment": BuiltInCategory.OST_ElectricalEquipment,
    "electrical fixtures": BuiltInCategory.OST_ElectricalFixtures,
    "lighting fixtures": BuiltInCategory.OST_LightingFixtures,
    "cable trays": BuiltInCategory.OST_CableTray,
    "conduits": BuiltInCategory.OST_Conduit,
    "sprinklers": BuiltInCategory.OST_Sprinklers,
    "rooms": BuiltInCategory.OST_Rooms,
    "spaces": BuiltInCategory.OST_MEPSpaces,
}


def get_elements(name):
    bic = CATEGORY_MAP.get(name.lower())

    if bic is None:
        raise Exception(
            "Category '%s' is not supported. Supported categories: %s"
            % (name, ", ".join(sorted(CATEGORY_MAP.keys())))
        )

    return (
        FilteredElementCollector(doc)
        .OfCategory(bic)
        .WhereElementIsNotElementType()
        .ToElements()
    )


def element_id_value(el):
    eid = el.Id

    try:
        return int(eid.Value)          # Revit 2024 and later
    except AttributeError:
        return int(eid.IntegerValue)   # Revit 2023 and earlier


def get_param(el, name):
    return el.LookupParameter(name)


def read_value(p):
    if p is None:
        return ""

    st = p.StorageType

    if st == StorageType.String:
        return p.AsString() or ""

    if st in (StorageType.Double, StorageType.Integer):
        return p.AsValueString() or ""

    if st == StorageType.ElementId:
        return p.AsValueString() or ""

    return ""


def write_value(p, text):
    """Returns True if the parameter value is successfully updated."""

    if p is None or p.IsReadOnly:
        return False

    st = p.StorageType

    if st == StorageType.String:
        return bool(p.Set(text))

    if st in (StorageType.Double, StorageType.Integer):
        if text == "":
            return False

        return bool(p.SetValueString(text))

    # ElementId parameters are not supported for import.
    return False


# ----------------------------------------------------------------
# CSV handling
# Simple Excel-compatible CSV functions supporting IronPython 2
# and CPython 3.

def csv_escape(s):
    s = "" if s is None else "%s" % s

    if any(c in s for c in [",", '"', "\n", "\r"]):
        s = '"' + s.replace('"', '""') + '"'

    return s


def csv_parse(text):
    rows, row, field, quoted, i, n = [], [], "", False, 0, len(text)

    while i < n:
        c = text[i]

        if quoted:
            if c == '"':
                if i + 1 < n and text[i + 1] == '"':
                    field += '"'
                    i += 1
                else:
                    quoted = False
            else:
                field += c

        else:
            if c == '"':
                quoted = True
            elif c == ",":
                row.append(field)
                field = ""
            elif c == "\n":
                row.append(field)
                rows.append(row)
                row, field = [], ""
            elif c != "\r":
                field += c

        i += 1

    if field != "" or row:
        row.append(field)
        rows.append(row)

    return rows


# ----------------------------------------------------------------
# Export parameters to CSV

def do_export():
    elements = get_elements(cat_name)

    header = ["ElementId", "Category", "Family and Type"] + param_names
    lines = [",".join(csv_escape(h) for h in header)]

    for el in elements:
        type_name = ""

        try:
            type_name = el.Name
        except Exception:
            pass

        row = [element_id_value(el), cat_name, type_name]

        for pn in param_names:
            row.append(read_value(get_param(el, pn)))

        lines.append(",".join(csv_escape(v) for v in row))

    with io.open(path, "w", encoding="utf-8-sig", newline="") as f:
        f.write("\r\n".join(lines) + "\r\n")

    return "Export completed: %d elements -> %s" % (len(elements), path)


# ----------------------------------------------------------------
# Import parameter values from CSV

def do_import():
    with io.open(path, "r", encoding="utf-8-sig") as f:
        rows = csv_parse(f.read())

    if not rows:
        return "The CSV file is empty."

    header = rows[0]

    if "ElementId" not in header:
        return "The CSV file does not contain an 'ElementId' column."

    id_col = header.index("ElementId")

    # Only parameters included in both the CSV header and
    # the input parameter list will be updated.
    cols = [
        (i, h) for i, h in enumerate(header)
        if h in param_names
    ]

    updated, skipped, missing = 0, 0, 0
    report = []

    t = Transaction(doc, "Parameter Manager - Import")
    t.Start()

    try:
        for r in rows[1:]:
            if len(r) <= id_col or r[id_col].strip() == "":
                continue

            el = doc.GetElement(ElementId(int(r[id_col])))

            if el is None:
                missing += 1
                report.append("Element %s was not found." % r[id_col])
                continue

            for i, pname in cols:
                new_val = r[i] if i < len(r) else ""
                p = get_param(el, pname)

                if p is None:
                    skipped += 1
                    continue

                if read_value(p) == new_val:
                    continue  # No change required.

                if write_value(p, new_val):
                    updated += 1
                else:
                    skipped += 1
                    report.append(
                        "Skipped: Element %s / Parameter %s "
                        "(read-only or invalid value)"
                        % (r[id_col], pname)
                    )

        t.Commit()

    except Exception as ex:
        t.RollBack()
        return "Error: All changes were rolled back. Details: %s" % ex

    summary = (
        "Import completed: %d values updated, %d skipped, "
        "%d elements not found"
        % (updated, skipped, missing)
    )

    return [summary] + report[:50]


# ----------------------------------------------------------------
# Main execution

if not run:
    OUT = "Run toggle is False. No action was performed."

elif mode == "export":
    OUT = do_export()

elif mode == "import":
    OUT = do_import()

else:
    OUT = "Mode must be either 'export' or 'import'."

A QA check that never changes the model. It writes every problem it finds to a CSV report you can filter in Excel.

CheckMeaning
EMPTY PARAMETERA required parameter is missing from the element or has no value.
NOT TAGGEDThe element has no tag in any view. Rooms and Spaces are skipped.

Inputs

IN[1]Required parameters["Mark", "Comments"];
IN[2]Report file path"C:\\Temp\\model_check.csv";
IN[3]Run toggletrue;

Procedure

  1. Create the node with 4 inputs and wire the Code Blocks as shown above.

  4. Fix the problems in Revit, then run again (see step 7 of the setup guide).
model_checker.py
# -*- coding: utf-8 -*-
"""
Model Checker v2 - Dynamo Python Script Node (Revit)
READ-ONLY QA/QC check. It never changes the model.

Checks:
  1. EMPTY PARAMETER : required parameter is missing or empty
  2. NOT TAGGED      : element has no tag in any view
                       (skipped for Rooms and Spaces)
  3. DUPLICATE       : same type at the same location

v2 change: tag detection tries several Revit API methods and REPORTS
how many tags it found, so a detection problem is visible in the output.

SETUP IN DYNAMO:
  1. Add a Python Script node (PythonNet3 engine) and paste this code.
  2. Add 4 inputs (IN[0] ... IN[3]):
       IN[0]  categories  : ["Ducts", "Pipes", "Mechanical Equipment"]
       IN[1]  required    : ["Mark", "Comments", "System Name"]
       IN[2]  report path : "C:\\Temp\\model_check.csv"
       IN[3]  run         : true
  3. Connect a Watch node to OUT and click Run.
  4. Open the CSV report in Excel. Fix the problems in Revit.

NOTE: After the model changes in Revit (for example you add tags),
Dynamo may not re-run this node by itself. Change IN[3] to false and
back to true, or open the node and click Save Changes, then Run.
"""

import clr
import io

clr.AddReference("RevitAPI")
clr.AddReference("RevitServices")

from Autodesk.Revit.DB import (
    FilteredElementCollector, BuiltInCategory, StorageType,
    IndependentTag, LocationPoint, LocationCurve
)
from RevitServices.Persistence import DocumentManager

doc = DocumentManager.Instance.CurrentDBDocument

cat_names = IN[0] if isinstance(IN[0], list) else [IN[0]]
cat_names = [str(c).strip() for c in cat_names]
required = [str(p) for p in IN[1]]
path = IN[2]
run = IN[3]

# ----------------------------------------------------------------
# Helpers

CATEGORY_MAP = {
    "ducts": BuiltInCategory.OST_DuctCurves,
    "duct fittings": BuiltInCategory.OST_DuctFitting,
    "duct accessories": BuiltInCategory.OST_DuctAccessory,
    "air terminals": BuiltInCategory.OST_DuctTerminal,
    "pipes": BuiltInCategory.OST_PipeCurves,
    "pipe fittings": BuiltInCategory.OST_PipeFitting,
    "pipe accessories": BuiltInCategory.OST_PipeAccessory,
    "mechanical equipment": BuiltInCategory.OST_MechanicalEquipment,
    "plumbing fixtures": BuiltInCategory.OST_PlumbingFixtures,
    "electrical equipment": BuiltInCategory.OST_ElectricalEquipment,
    "electrical fixtures": BuiltInCategory.OST_ElectricalFixtures,
    "lighting fixtures": BuiltInCategory.OST_LightingFixtures,
    "cable trays": BuiltInCategory.OST_CableTray,
    "conduits": BuiltInCategory.OST_Conduit,
    "sprinklers": BuiltInCategory.OST_Sprinklers,
    "rooms": BuiltInCategory.OST_Rooms,
    "spaces": BuiltInCategory.OST_MEPSpaces,
}

NO_TAG_CHECK = ("rooms", "spaces")


def id_value(eid):
    try:
        return int(eid.Value)          # Revit 2024 and later
    except AttributeError:
        return int(eid.IntegerValue)   # Revit 2023 and earlier


def get_elements(name):
    bic = CATEGORY_MAP.get(name.lower())

    if bic is None:
        raise Exception(
            "Category '%s' is not supported. Supported categories: %s"
            % (name, ", ".join(sorted(CATEGORY_MAP.keys())))
        )

    return (
        FilteredElementCollector(doc)
        .OfCategory(bic)
        .WhereElementIsNotElementType()
        .ToElements()
    )


def type_name(el):
    try:
        return el.Name
    except Exception:
        return ""


def is_empty(p):
    """True if the parameter has no usable value."""
    if p is None:
        return True

    st = p.StorageType

    if st == StorageType.String:
        return (p.AsString() or "").strip() == ""

    return not p.HasValue


def tagged_ids():
    """
    Returns (set of tagged element ids, number of tags found, errors).
    Tries three Revit API methods, newest first.
    """
    result = set()
    tag_count = 0
    errors = []

    for tag in FilteredElementCollector(doc).OfClass(IndependentTag).ToElements():
        tag_count += 1
        found = []

        # Method 1: Revit 2022 and later
        try:
            for eid in tag.GetTaggedLocalElementIds():
                found.append(id_value(eid))
        except Exception as ex1:
            # Method 2: Revit 2022 and later, returns LinkElementId
            try:
                for lid in tag.GetTaggedElementIds():
                    found.append(id_value(lid.HostElementId))
            except Exception as ex2:
                # Method 3: Revit 2021 and earlier
                try:
                    found.append(id_value(tag.TaggedLocalElementId))
                except Exception as ex3:
                    if len(errors) < 3:
                        errors.append(str(ex1))

        result.update(found)

    return result, tag_count, errors


def location_key(el):
    """Rounded location, used to find duplicate elements."""
    loc = el.Location

    def r(pt):
        return (round(pt.X, 3), round(pt.Y, 3), round(pt.Z, 3))

    if isinstance(loc, LocationPoint):
        return ("P", r(loc.Point))

    if isinstance(loc, LocationCurve):
        c = loc.Curve
        a, b = r(c.GetEndPoint(0)), r(c.GetEndPoint(1))
        return ("C",) + tuple(sorted([a, b]))

    return None


def csv_escape(s):
    s = "" if s is None else "%s" % s

    if any(c in s for c in [",", '"', "\n", "\r"]):
        s = '"' + s.replace('"', '""') + '"'

    return s


# ----------------------------------------------------------------
# Run all checks

def run_checks():
    issues = []   # (check, element_id, category, type, detail)
    total = 0
    tag_info = None   # (tags found, elements tagged, errors)
    tags = None

    for cat in cat_names:
        elements = get_elements(cat)
        total += len(elements)

        # 1. Empty required parameters
        for el in elements:
            for pn in required:
                p = el.LookupParameter(pn)

                if p is None:
                    issues.append(("EMPTY PARAMETER", id_value(el.Id), cat,
                                   type_name(el),
                                   "Parameter '%s' does not exist" % pn))
                elif is_empty(p):
                    issues.append(("EMPTY PARAMETER", id_value(el.Id), cat,
                                   type_name(el),
                                   "Parameter '%s' is empty" % pn))

        # 2. Not tagged
        if cat.lower() not in NO_TAG_CHECK:
            if tags is None:
                tags, tag_count, tag_errors = tagged_ids()
                tag_info = (tag_count, len(tags), tag_errors)

            for el in elements:
                if id_value(el.Id) not in tags:
                    issues.append(("NOT TAGGED", id_value(el.Id), cat,
                                   type_name(el), "No tag in any view"))

        # 3. Duplicates (same type at same location)
        seen = {}

        for el in elements:
            key = location_key(el)

            if key is None:
                continue

            key = (el.GetTypeId().ToString(), key)

            if key in seen:
                issues.append(("DUPLICATE", id_value(el.Id), cat,
                               type_name(el),
                               "Same type and location as element %s"
                               % seen[key]))
            else:
                seen[key] = id_value(el.Id)

    return issues, total, tag_info


def write_report(issues):
    header = ["Check", "ElementId", "Category", "Family and Type", "Detail"]
    lines = [",".join(csv_escape(h) for h in header)]

    for row in issues:
        lines.append(",".join(csv_escape(v) for v in row))

    with io.open(path, "w", encoding="utf-8-sig", newline="") as f:
        f.write("\r\n".join(lines) + "\r\n")


# ----------------------------------------------------------------
# Main execution

if not run:
    OUT = "Run toggle is False. No action was performed."

else:
    try:
        found, total, tag_info = run_checks()
        write_report(found)

        counts = {}
        for row in found:
            counts[row[0]] = counts.get(row[0], 0) + 1

        OUT = [
            "Checked %d elements. Issues found: %d" % (total, len(found)),
            "EMPTY PARAMETER: %d" % counts.get("EMPTY PARAMETER", 0),
            "NOT TAGGED: %d" % counts.get("NOT TAGGED", 0),
            "DUPLICATE: %d" % counts.get("DUPLICATE", 0),
        ]

        if tag_info is not None:
            OUT.append("Tags found in project: %d, elements tagged: %d"
                       % (tag_info[0], tag_info[1]))

            if tag_info[2]:
                OUT.append("Tag read error: %s" % tag_info[2][0])

        OUT.append("Report saved: %s" % path)

    except Exception as ex:
        OUT = "Error: %s" % ex
Changes the modelRevit 2022+

3. Auto-Tagger

Tags every untagged element of the chosen categories in the active view. Elements that already have a tag in that view are skipped.

Inputs

PortWhatExample
IN[0]Categories["Ducts", "Air Terminals"];
IN[1]Position"middle"; tag on the element, no leader
"offset"; tag beside the element, with a leader
IN[2]Offset distance in millimetres (used by "offset")300;
IN[3]Run toggletrue;

Use one position at a time. If tags overlap with "middle", press Ctrl+Z in Revit and run again with "offset".

Procedure

  1. In Revit, open a plan, section or elevation view and keep it active. The script tags in whichever view is open.
  2. Make sure the tag families for your categories are loaded: Insert > Load Family > Annotations > MEP.
  3. Create the node with 4 inputs, wire the Code Blocks, paste the script, and run.
  4. The Watch node shows the view name, how many elements are in the view, how many were already tagged, and how many new tags were created or failed.
  5. Review the view. Ctrl+Z in Revit removes all the new tags in one step.
auto_tagger.py
# -*- coding: utf-8 -*-
"""
Auto-Tagger - Dynamo Python Script Node (Revit 2022 or later)
Tags every UNTAGGED element of the chosen categories in the ACTIVE VIEW.

- Elements that already have a tag in the active view are skipped.
- Tag type = the default tag family loaded in the project for that category
  (for example Duct Tag, Air Terminal Tag).
- All tags are created in ONE transaction, so Ctrl+Z in Revit undoes them all.

SETUP IN DYNAMO:
  1. Add a Python Script node (PythonNet3 engine) and paste this code.
  2. Add 4 inputs (IN[0] ... IN[3]):
       IN[0]  categories : ["Ducts", "Air Terminals"]
       IN[1]  position   : "middle"  (tag sits on the element, no leader)
                           "offset"  (tag sits beside the element, with leader)
       IN[2]  offset     : 300   (millimetres, used only for "offset")
       IN[3]  run        : true
  3. Connect a Watch node to OUT.
  4. In Revit, open a PLAN, SECTION or ELEVATION view first.
     Dynamo tags in whichever view is active in Revit.
  5. Click Run.

NOTE: If you run it again after changing the model, Dynamo may not
re-run the node. Change IN[3] to false and back to true, then Run.
"""

cat_names = IN[0] if isinstance(IN[0], list) else [IN[0]]
cat_names = [str(c).strip() for c in cat_names]
position = str(IN[1]).strip().lower()
offset_mm = float(IN[2])
run = IN[3]

    "cable trays": BuiltInCategory.OST_CableTray,

    "sprinklers": BuiltInCategory.OST_Sprinklers,

    ViewType.FloorPlan, ViewType.CeilingPlan, ViewType.EngineeringPlan,

def id_value(eid):
    try:
        return int(eid.Value)          # Revit 2024 and later

def elements_in_view(name):
    bic = CATEGORY_MAP.get(name.lower())

    if bic is None:
        raise Exception(
            "Category '%s' is not supported. Supported categories: %s"
            % (name, ", ".join(sorted(CATEGORY_MAP.keys())))

    return (
        FilteredElementCollector(doc, view.Id)
        .OfCategory(bic)
        .WhereElementIsNotElementType()
        .ToElements()

def tagged_in_view():
    """Returns (set of element ids already tagged in this view, tag count)."""
    result = set()
    tag_count = 0

    for tag in FilteredElementCollector(doc, view.Id).OfClass(IndependentTag).ToElements():
        tag_count += 1

        try:
            for eid in tag.GetTaggedLocalElementIds():
                result.add(id_value(eid))
        except Exception:
            try:
                for lid in tag.GetTaggedElementIds():
                    result.add(id_value(lid.HostElementId))
            except Exception:
                try:
                    result.add(id_value(tag.TaggedLocalElementId))
                except Exception:
                    pass

    return result, tag_count


def element_point(el):
    """Middle point of the element in model coordinates."""
    loc = el.Location

    pt = getattr(loc, "Point", None)            # point-based elements
    if pt is not None:
        return pt

    crv = getattr(loc, "Curve", None)           # curve-based (ducts, pipes)
    if crv is not None:
        return crv.Evaluate(0.5, True)

    bb = el.get_BoundingBox(view)               # fallback
    if bb is not None:
        return bb.Min.Add(bb.Max).Multiply(0.5)

    return None

           % (view.Name, view.ViewType))

        # Stop, otherwise every element would get a second tag.
        if tag_count > 0 and len(already) == 0:
            raise Exception(
                "The view has %d tags but their tagged elements could not "
                "be read. Stopped to avoid double tagging." % tag_count)

        todo = []
        in_view = 0

        for cat in cat_names:
            for el in elements_in_view(cat):
                in_view += 1

                if id_value(el.Id) not in already:
                    todo.append(el)

        offset_ft = offset_mm / 304.8   # Revit works in feet
        use_leader = (position == "offset")

        created, failed = 0, 0
        errors = []

        t = Transaction(doc, "Auto-Tagger")
        t.Start()

        try:
            for el in todo:
                pt = element_point(el)

                if pt is None:
                    failed += 1
                    errors.append("Element %d: no location" % id_value(el.Id))
                    continue

                if use_leader:
                    pt = pt.Add(view.UpDirection.Multiply(offset_ft))

                try:
                    IndependentTag.Create(
                        doc, view.Id, Reference(el), use_leader,
                        TagMode.TM_ADDBY_CATEGORY,
                        TagOrientation.Horizontal, pt)
                    created += 1
                except Exception as ex:
                    failed += 1

                    if len(errors) < 3:
                        errors.append("Element %d: %s"
                                      % (id_value(el.Id), ex))

            t.Commit()

        except Exception as ex:
            t.RollBack()
            raise

        OUT = [
            "View: %s" % view.Name,
            "Elements in view: %d, already tagged: %d"
            % (in_view, in_view - len(todo)),
            "New tags created: %d, failed: %d" % (created, failed),
        ] + errors

        if failed and created == 0:
            OUT.append("Tip: check that the tag family (for example Duct Tag) "
                       "is loaded in the project.")

    except Exception as ex:
        OUT = "Error: %s" % ex

# -*- coding: utf-8 -*-
"""
Quantity Takeoff (BOQ) - Dynamo Python Script Node (Revit)
READ-ONLY. Counts elements and adds up lengths and areas, grouped by
category, family and type, and any parameters you choose.
The result is a CSV file that opens in Excel.

Output columns:
  Category | Family and Type | <your group parameters> |
  Count | Total Length (m) | Total Area (m2)

- Length and area are filled for duct, pipe, cable tray and conduit runs.
  They are blank for fittings, equipment and terminals (count only).
- A TOTAL row is added after each category.

SETUP IN DYNAMO:
  1. Add a Python Script node (PythonNet3 engine) and paste this code.
  2. Add 4 inputs (IN[0] ... IN[3]):
       IN[0]  categories    : ["Ducts", "Pipes", "Duct Fittings", "Air Terminals"]
       IN[1]  group by      : ["Size", "System Type"]   (parameter names)
       IN[2]  report path   : "C:\\Temp\\boq.csv"
       IN[3]  run           : true
  3. Connect a Watch node to OUT and click Run.
  4. Open the CSV in Excel.

NOTE: After you change the model, Dynamo may not re-run the node.
Change IN[3] to false and back to true, then Run.
"""

import clr
import io

clr.AddReference("RevitAPI")
clr.AddReference("RevitServices")

from Autodesk.Revit.DB import (
    FilteredElementCollector, BuiltInCategory, BuiltInParameter, StorageType
)
from RevitServices.Persistence import DocumentManager

doc = DocumentManager.Instance.CurrentDBDocument

cat_names = IN[0] if isinstance(IN[0], list) else [IN[0]]
cat_names = [str(c).strip() for c in cat_names]

group_params = IN[1] if isinstance(IN[1], list) else [IN[1]]
group_params = [str(p).strip() for p in group_params if p is not None and str(p).strip() != ""]

path = IN[2]
run = IN[3]

FT_TO_M = 0.3048
FT2_TO_M2 = 0.09290304

# Built-in parameters (looked up safely, so a missing name never stops the script)
BIP_LENGTH = getattr(BuiltInParameter, "CURVE_ELEM_LENGTH", None)
BIP_AREA = getattr(BuiltInParameter, "RBS_CURVE_SURFACE_AREA", None)
BIP_FAMILY_TYPE = getattr(BuiltInParameter, "ELEM_FAMILY_AND_TYPE_PARAM", None)

# ----------------------------------------------------------------
# Helpers

CATEGORY_MAP = {
    "ducts": BuiltInCategory.OST_DuctCurves,
    "duct fittings": BuiltInCategory.OST_DuctFitting,
    "duct accessories": BuiltInCategory.OST_DuctAccessory,
    "air terminals": BuiltInCategory.OST_DuctTerminal,
    "pipes": BuiltInCategory.OST_PipeCurves,
    "pipe fittings": BuiltInCategory.OST_PipeFitting,
    "pipe accessories": BuiltInCategory.OST_PipeAccessory,
    "mechanical equipment": BuiltInCategory.OST_MechanicalEquipment,
    "plumbing fixtures": BuiltInCategory.OST_PlumbingFixtures,
    "electrical equipment": BuiltInCategory.OST_ElectricalEquipment,
    "electrical fixtures": BuiltInCategory.OST_ElectricalFixtures,
    "lighting fixtures": BuiltInCategory.OST_LightingFixtures,
    "cable trays": BuiltInCategory.OST_CableTray,
    "conduits": BuiltInCategory.OST_Conduit,
    "sprinklers": BuiltInCategory.OST_Sprinklers,
}


def get_elements(name):
    bic = CATEGORY_MAP.get(name.lower())

    if bic is None:
        raise Exception(
            "Category '%s' is not supported. Supported categories: %s"
            % (name, ", ".join(sorted(CATEGORY_MAP.keys())))
        )

    return (
        FilteredElementCollector(doc)
        .OfCategory(bic)
        .WhereElementIsNotElementType()
        .ToElements()

def param_text(p):
    """Parameter value as text, using the project display units."""
    if p is None:
        return ""

    if p.StorageType == StorageType.String:
        return p.AsString() or ""

    return p.AsValueString() or ""


def family_and_type(el):
    if BIP_FAMILY_TYPE is not None:
        try:
            p = el.get_Parameter(BIP_FAMILY_TYPE)
            txt = p.AsValueString() if p is not None else None

            if txt:
                return txt
        except Exception:
            pass

    try:
        return el.Name
    except Exception:
        return ""


def double_param(el, bip):
    """Parameter value in Revit internal units (feet), or None."""
    if bip is None:
        return None

    p = el.get_Parameter(bip)

    if p is None or not p.HasValue:
        return None

    return p.AsDouble()


def csv_escape(s):
    s = "" if s is None else "%s" % s

    if any(c in s for c in [",", '"', "\n", "\r"]):
        s = '"' + s.replace('"', '""') + '"'

    return s


def fmt(v):
    return "" if v is None else "%.2f" % v


# ----------------------------------------------------------------
# Build the takeoff

def build_takeoff():
    groups = {}
    totals = {}
    elements_counted = 0

    for cat in cat_names:
        totals[cat] = {"count": 0, "length": None, "area": None}

        for el in get_elements(cat):
            elements_counted += 1

            key = (cat, family_and_type(el)) + tuple(
                param_text(el.LookupParameter(n)) for n in group_params
            )

            g = groups.get(key)

            if g is None:
                g = {"count": 0, "length": None, "area": None}
                groups[key] = g

            length = double_param(el, BIP_LENGTH)
            area = double_param(el, BIP_AREA)

            for bucket in (g, totals[cat]):
                bucket["count"] += 1

                if length is not None:
                    bucket["length"] = (bucket["length"] or 0.0) + length * FT_TO_M

                if area is not None:
                    bucket["area"] = (bucket["area"] or 0.0) + area * FT2_TO_M2

    return groups, totals, elements_counted


def write_report(groups, totals):
    header = (["Category", "Family and Type"] + group_params
              + ["Count", "Total Length (m)", "Total Area (m2)"])
    lines = [",".join(csv_escape(h) for h in header)]
    rows = 0

    for cat in cat_names:
        keys = sorted(k for k in groups if k[0] == cat)

        for k in keys:
            g = groups[k]
            row = list(k) + [g["count"], fmt(g["length"]), fmt(g["area"])]
            lines.append(",".join(csv_escape(v) for v in row))
            rows += 1

        t = totals[cat]
        row = ([cat, "TOTAL"] + [""] * len(group_params)
               + [t["count"], fmt(t["length"]), fmt(t["area"])])
        lines.append(",".join(csv_escape(v) for v in row))
        rows += 1

    with io.open(path, "w", encoding="utf-8-sig", newline="") as f:
        f.write("\r\n".join(lines) + "\r\n")

    return rows


# ----------------------------------------------------------------
# Main execution

if not run:
    OUT = "Run toggle is False. No action was performed."

else:
    try:
        groups, totals, counted = build_takeoff()
        rows = write_report(groups, totals)

        OUT = ["Elements counted: %d. Rows in report: %d" % (counted, rows)]

        for cat in cat_names:
            t = totals[cat]
            line = "%s: %d elements" % (cat, t["count"])

            if t["length"] is not None:
                line += ", %.2f m" % t["length"]

            OUT.append(line)

        OUT.append("Report saved: %s" % path)

    except Exception as ex:
        OUT = "Error: %s" % ex

def find_title_block():
    """Returns (symbol, available names)."""
    symbols = list(
        FilteredElementCollector(doc)
        .OfCategory(BuiltInCategory.OST_TitleBlocks)
        .WhereElementIsElementType()
        .ToElements()
    )

    for s in symbols:
        names.append("%s: %s" % (s.FamilyName, s.Name))

        return symbols[0], names

    q = tb_name.lower()

    for s in symbols:
        full = ("%s: %s" % (s.FamilyName, s.Name)).lower()

        if q in (s.Name.lower(), s.FamilyName.lower(), full):
            return s, names

    return None, names

        return None

    for v in FilteredElementCollector(doc).OfClass(View).ToElements():
        if v.IsTemplate and v.Name == template_name:

else:

                        placed.add(id_value(view.Id))
                        placed_count += 1
                        sheet_list.append("%s  %s" % (number, name))
                    else:
                        errors.append("%s: view could not be placed on its sheet" % name)

                except Exception as ex:
                    if len(errors) < 5:
                        errors.append("%s: %s" % (lvl.Name, ex))

            t.Commit()

        except Exception:
            t.RollBack()
            raise

            "Views created: %d, reused: %d" % (views_created, views_reused),

        ] + sheet_list

    except Exception as ex:
        OUT = "Error: %s" % ex

doc = DocumentManager.Instance.CurrentDBDocument

mode = "" if IN[0] is None else str(IN[0]).strip().lower()
path = IN[1]
default_tb = "" if IN[2] is None else str(IN[2]).strip()
run = IN[3]

KNOWN = ("sheetnumber", "sheetname", "titleblock", "view")

# ----------------------------------------------------------------
# Helpers


def csv_escape(s):
    s = "" if s is None else "%s" % s

    if any(c in s for c in [",", '"', "\n", "\r"]):
        s = '"' + s.replace('"', '""') + '"'

    return s


def csv_parse(text, delim):
    rows, row, field, quoted, i, n = [], [], "", False, 0, len(text)

    while i < n:
        c = text[i]

        if quoted:
            if c == '"':
                if i + 1 < n and text[i + 1] == '"':
                    field += '"'
                    i += 1
                else:
                    quoted = False
            else:
                field += c

        else:
            if c == '"':
                quoted = True
            elif c == delim:
                row.append(field)
                field = ""
            elif c == "\n":
                row.append(field)
                rows.append(row)
                row, field = [], ""
            elif c != "\r":
                field += c

        i += 1

    if field != "" or row:
        row.append(field)
        rows.append(row)

    return rows


def title_blocks():
    return list(
        FilteredElementCollector(doc)
        .OfCategory(BuiltInCategory.OST_TitleBlocks)
        .WhereElementIsElementType()
        .ToElements()
    )


def tb_label(s):
    return "%s: %s" % (s.FamilyName, s.Name)


def match_title_block(symbols, name):
    if not symbols:
        return None

    if name == "":
        return symbols[0]

    q = name.lower()

    for s in symbols:
        if q in (s.Name.lower(), s.FamilyName.lower(), tb_label(s).lower()):
            return s

    return None


def set_param(p, text):
    if p is None or p.IsReadOnly or text == "":
        return False

    st = p.StorageType

    if st == StorageType.String:
        return bool(p.Set(text))

    if st in (StorageType.Double, StorageType.Integer):
        return bool(p.SetValueString(text))

    return False

# Template mode

def do_template():
    lines = [
        "SheetNumber,SheetName,TitleBlock,View",
        "M-101,Ground Floor HVAC Plan,,HVAC - Ground Floor FFL",
        "M-102,First Floor HVAC Plan,,",
    ]

    with io.open(path, "w", encoding="utf-8-sig", newline="") as f:
        f.write("\r\n".join(lines) + "\r\n")

    out = [
        "Template saved: %s" % path,
        "Edit it in Excel: replace or delete the 2 sample rows, then save as CSV UTF-8.",
        "Add more columns to fill sheet parameters, for example: Drawn By, Checked By",
        "Title blocks in this project:",
    ]

    for s in title_blocks():
        out.append("  " + tb_label(s))

    return out

# Create mode

def do_create():
    with io.open(path, "r", encoding="utf-8-sig") as f:
        text = f.read()

    first_line = text.split("\n")[0] if text else ""
    delim = ";" if first_line.count(";") > first_line.count(",") else ","

    rows = csv_parse(text, delim)

    if not rows:
        return "The CSV file is empty."

    header = [h.strip() for h in rows[0]]
    low = [h.lower() for h in header]

    for req in ("sheetnumber", "sheetname"):
        if req not in low:
            return "The CSV needs a '%s' column." % (
                "SheetNumber" if req == "sheetnumber" else "SheetName")

    def col(name):
        return low.index(name) if name in low else None

    c_num, c_name = col("sheetnumber"), col("sheetname")
    c_tb, c_view = col("titleblock"), col("view")
    extra = [(i, h) for i, h in enumerate(header)
             if h != "" and h.lower() not in KNOWN]

    def cell(r, i):
        if i is None or i >= len(r):
            return ""
        return r[i].strip()

    symbols = title_blocks()

    if not symbols:
        return "No title block family is loaded in the project."

    existing = set(
        s.SheetNumber for s in FilteredElementCollector(doc).OfClass(ViewSheet).ToElements())

    skip_types = (ViewType.DrawingSheet, ViewType.ProjectBrowser,
                  ViewType.SystemBrowser, ViewType.Internal)
    view_by_name = {}

    for v in FilteredElementCollector(doc).OfClass(View).ToElements():
        if not v.IsTemplate and v.ViewType not in skip_types:
            view_by_name[v.Name] = v

    # ---- check every row before touching the model
    todo = []
    problems = []
    seen = set()

    for n, r in enumerate(rows[1:], start=2):
        number, name = cell(r, c_num), cell(r, c_name)

        if number == "" and name == "":
            continue

        if number == "" or name == "":
            problems.append("Row %d: SheetNumber and SheetName are both needed" % n)
            continue

        if number in existing:
            problems.append("Row %d: sheet %s already exists, skipped" % (n, number))
            continue

        if number in seen:
            problems.append("Row %d: sheet %s is repeated in the CSV, skipped" % (n, number))
            continue

        tb_text = cell(r, c_tb) or default_tb
        tb = match_title_block(symbols, tb_text)

        if tb is None:
            problems.append("Row %d: title block '%s' not found" % (n, tb_text))
            continue

        seen.add(number)
        todo.append((n, number, name, tb, cell(r, c_view), r))

    created, placed, params_set = 0, 0, 0
    messages = []

    t = Transaction(doc, "Batch Sheet Maker")
    t.Start()

    try:
        activated = False

        for tb in set(item[3] for item in todo):
            if not tb.IsActive:
                tb.Activate()
                activated = True

        if activated:
            doc.Regenerate()

        for n, number, name, tb, view_name, r in todo:
            try:
                sheet = ViewSheet.Create(doc, tb.Id)

                try:
                    sheet.SheetNumber = number
                    sheet.Name = name
                except Exception as ex:
                    doc.Delete(sheet.Id)
                    problems.append("Row %d: %s (%s)" % (n, number, ex))
                    continue

                created += 1

                for i, h in extra:
                    if set_param(sheet.LookupParameter(h), cell(r, i)):
                        params_set += 1

                if view_name != "":
                    v = view_by_name.get(view_name)

                    if v is None:
                        messages.append("%s: view '%s' not found" % (number, view_name))
                        continue

                    o = sheet.Outline

                    try:
                        if v.ViewType == ViewType.Schedule:
                            ScheduleSheetInstance.Create(
                                doc, sheet.Id, v.Id,
                                XYZ(o.Min.U + 0.15, o.Max.V - 0.15, 0))
                            placed += 1
                        elif Viewport.CanAddViewToSheet(doc, sheet.Id, v.Id):
                            Viewport.Create(
                                doc, sheet.Id, v.Id,
                                XYZ((o.Min.U + o.Max.U) / 2.0,
                                    (o.Min.V + o.Max.V) / 2.0, 0))
                            placed += 1
                        else:
                            messages.append(
                                "%s: view '%s' is already on another sheet" % (number, view_name))
                    except Exception as ex:
                        messages.append("%s: could not place '%s' (%s)" % (number, view_name, ex))

            except Exception as ex:
                problems.append("Row %d: %s (%s)" % (n, number, ex))

        t.Commit()

    except Exception:
        t.RollBack()
        raise

    out = [
        "Sheets created: %d, views placed: %d, sheet parameters set: %d"
        % (created, placed, params_set),
    ]

    out += messages[:10]
    out += problems[:10]

    if len(messages) + len(problems) > 20:
        out.append("...more messages not shown")

    return out


# ----------------------------------------------------------------
# Main execution

if not run:
    OUT = "Run toggle is False. No action was performed."

elif mode == "template":
    try:
        OUT = do_template()
    except Exception as ex:
        OUT = "Error: %s" % ex

elif mode == "create":
    try:
        OUT = do_create()
    except Exception as ex:
        OUT = "Error: %s" % ex

else:
    OUT = "Mode must be 'template' or 'create'."
